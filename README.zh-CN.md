# Global Diesel：面向海外销售的排放法规与产品选型工具

**[打开在线网站 →](https://diesel.jamesky.site)** · [English](README.md)

给海外客户报一台柴油机之前，销售要先回答三个问题：*这个国家现在执行什么排放法规？我们哪些
机型满足？怎么清楚地讲给客户听？* 平时这些都要靠人工翻外国法规、产品规格书和表格。

我在一家柴油机厂做海外营销，做了这个工具，把这件事变成点几下就能完成。

## 能做什么

**1. 在世界地图上看法规。** 选一个国家，就能看到当前生效和即将实施的排放法规，每条都附
官方来源链接。

![排放法规世界地图](docs/images/map.jpg)

**2. 按目标市场选机型。** 选择国家、应用场景（卡车、客车、工程机械、农业机械、发电机组、
船用）和所需功率，工具会列出声明满足当地全部现行法规的机型，并标出不满足的。

![德国 300 kW 卡车的选型结果](docs/images/products.jpg)

**3. 一键导出客户简报。** 把适用法规和推荐机型整理成一页简报，支持英文、中文、西班牙文、
葡萄牙文、俄文和阿拉伯文，可直接打印或存成 PDF。

![客户简报](docs/images/brief.jpg)

**4. 问 AI 助手。** 用中文或英文直接提问，比如“比较中国和巴西 100 kW 非道路机械的法规”，
回答都会附上来源。

## 为什么结果可信

- **事实来自核实过的数据，不是 AI 编的。** 法规从官方来源录入，审核后才发布；AI 只能查询
  和解释这些数据。
- **每个结论都标出处**，并注明来源的核验日期。
- **没有数据就直说。** 某个国家或功率段缺数据时，工具会明确提示，不会凭空给答案。

## 技术说明

基于 Next.js、TypeScript、PostgreSQL 和兼容 OpenAI 接口的大模型构建，每次改动都有自动化
测试和 CI 检查。用演示数据在本地运行（不需要数据库或 API key）：

```bash
pnpm install
pnpm demo
```
